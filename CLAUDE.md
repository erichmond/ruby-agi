# ruby-agi

Fork of ruby-agi library for writing AGI (Asterisk Gateway Interface) scripts in Ruby.

## Purpose

Library for building Asterisk telephony applications in Ruby. This fork fixes ActiveRecord compatibility issues from the original v1.1.2.

## Structure

- `lib/` - Core library code
- `examples/` - Example AGI scripts
- `ruby-agi.gemspec` - Gem specification

## Note

Historical/archived project. Original ruby-agi is at rubyforge.
